# Employee Attrition Prediction Model

A machine learning project that predicts whether an employee is likely to leave (attrite) a company, based on HR and workplace data. The project covers data exploration, visualization, and model building using Python and Jupyter Notebook.

## 📁 Repository Structure

```
Employee-Attrition-Prediction-Model-/
├── Dataset/     # Raw/processed dataset used for training and evaluation
├── Notebook/    # Jupyter notebook(s) with EDA, preprocessing, and modeling
├── charts/      # Visualizations and plots generated during analysis
└── README.md
```

## 📊 Overview

Employee attrition is a major concern for organizations, as losing skilled employees is costly in terms of hiring, training, and productivity. This project analyzes historical employee data to uncover the key factors driving attrition and builds a predictive model to flag employees at risk of leaving.

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook
- Common data science libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

### Installation
```bash
git clone https://github.com/Abhieeeh/Employee-Attrition-Prediction-Model-.git
cd Employee-Attrition-Prediction-Model-
pip install -r requirements.txt
```

### Usage
1. Open the notebook inside the `Notebook/` folder using Jupyter:
   ```bash
   jupyter notebook Notebook/
   ```
2. Run the cells in order to reproduce the data exploration, preprocessing, and model training steps.
3. Generated charts and visualizations can be found in the `charts/` folder.

## 🧠 Workflow

- **Data Exploration & Cleaning** – Understanding the dataset, handling missing values, and preparing features.
- **Exploratory Data Analysis (EDA)** – Visualizing trends and relationships related to attrition.
- **Feature Engineering** – Encoding categorical variables and preparing data for modeling.
- **Model Building** – Training classification models to predict attrition.
- **Evaluation** – Assessing model performance using relevant metrics (accuracy, precision, recall, F1-score, etc.).
